# StudyTracker

## Project Description
Students often know their exam date but not how much they need to study each day.
StudyTracker lets a student add subjects, set exam dates and upload study documents.
It counts the pages and calculates a daily study goal so the student finishes before the exam.

## Objective
Build a web application that turns course material and an exam date into a clear daily
study plan, tracks progress, and adjusts the plan when the student falls behind.

## Target Users
University and high-school students preparing for exams, and self-learners preparing
for certificates or language exams.

## Planned Technologies
- Backend: Java, Spring Boot (REST API)
- Frontend: React
- Database: MySQL
- PDF page counting: Apache PDFBox
- Deployment: Docker
- Later version: an AI service for generating practice exams
